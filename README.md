# Call Recorder Pro

برنامه‌ی اندروید ضبط مکالمه با چند روش ضبط و ابزارهای بهبود کیفیت صدا.

## ساخت APK

### روش ۱: GitHub Actions (بدون نصب چیزی)
1. یک ریپازیتوری جدید در GitHub بسازید و محتویات این پوشه را در آن آپلود کنید (پوشه‌ی `.github` هم باید باشد).
2. به تب **Actions** بروید و Workflow با نام **Build APK** را اجرا کنید (یا بعد از push خودکار اجرا می‌شود).
3. پس از پایان، فایل APK را از بخش **Artifacts** دانلود کنید.

### روش ۲: Android Studio
پوشه را با Android Studio باز کنید، سپس `Build > Build APK(s)`.

### روش ۳: خط فرمان
با JDK 17 و Android SDK نصب‌شده: `gradle :app:assembleRelease`
خروجی: `app/build/outputs/apk/release/`

## امکانات
- ضبط با ۶ منبع صدا (VOICE_CALL، VOICE_COMMUNICATION، VOICE_RECOGNITION، UNPROCESSED، MIC، CAMCORDER) و تغییر خودکار به منبع بعدی در صورت خطا یا سکوت
- روشن کردن خودکار بلندگو برای ضبط دو طرف با میکروفون
- شروع/توقف خودکار با تماس
- تقویت زنده هنگام ضبط
- کاهش نویز طیفی، فیلتر High-pass، اکولایزر ۵ باندی، کمپرسور، نرمال‌سازی و گین، با چند پریست
- پخش، اشتراک‌گذاری و حذف ضبط‌ها

## محدودیت‌های اندروید
از اندروید ۹ به بعد گوگل دسترسی برنامه‌های عادی به صدای خط تماس (VOICE_CALL) را بسته است. روی بیشتر گوشی‌ها
فقط ضبط از طریق میکروفون با بلندگوی روشن جواب می‌دهد. شروع ضبط خودکار از پس‌زمینه هم در اندروید ۱۲+
ممکن است توسط سیستم مسدود شود (مجوز «نمایش روی سایر برنامه‌ها» و استثنای باتری کمک می‌کند).

فایل‌ها در `Android/data/com.example.callrecorder/files/Recordings` ذخیره می‌شوند.
